# Encrypt-UI
## 又名 cryptUI
> 一款基于块间置换算法的文件加密/解密工具，提供图形界面。

![python 3.6+](https://img.shields.io/badge/python-3.6+-blue)
![AGPL](https://img.shields.io/badge/license-AGPL-white)

本工具采用块间置换（Block Permutation）加密，过程如下：

将输入文件划分为固定大小的块（最后一块用 0x00 填充）。

使用用户提供的密钥（字符串）生成一个伪随机排列（通过 SHA-256 作为种子，随机打乱块索引）。

按打乱后的顺序将块写入输出文件，并在文件头部记录原始文件大小（8 字节小端序）。

解密时，使用相同密钥重新生成相同的排列，计算其逆排列，然后按逆顺序读取块并写入输出文件，最后截断至原始大小（去除填充）。

该算法不依赖于复杂的数学变换，但随机排列提供了足够的数据混淆，密钥空间大，适合一般文件保护需求。
